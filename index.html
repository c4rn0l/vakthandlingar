Mailvakten monitors forwarded email delivery and helps ensure that expected messages reach their configured Gmail destinations.

Private home monitoring service

What Mailvakten does

Mailvakten compares messages received by configured source mailboxes with their expected Gmail destinations. It uses the Gmail API to verify delivery and, when a message is still missing after repeated checks, can import the original message into the intended Gmail mailbox.

The service is designed for private use and runs as part of the Vaktcentralen home monitoring platform.

Google data access

Mailvakten requests only the Gmail permissions needed to locate messages and restore missing deliveries. It does not use Gmail data for advertising, profiling, sale of data, or AI/model training.
